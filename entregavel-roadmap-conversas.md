# Roadmap de Conversas — 1ª Semana

**Martin Fabichak · Code Leadership** · Workshop Roadmap Tech Lead

1:1 de 1 hora com cada pessoa: primeiro o time, depois os colegas (PM, PO, Designer…). Objetivo: se conectar, entender de onde cada pessoa vem e seus objetivos, criar expectativa positiva e clara para o primeiro mês.

---

## Regras das conversas

**Perguntar (time):** no que a equipe é boa? no que ela é ruim? o que funciona? o que te irrita? o que você mudaria amanhã?
**Perguntar (colegas):** o que funciona? o que te irrita? o que você mudaria amanhã? Como é a colaboração com os devs?
**NÃO fazer:** prometer mudanças, criticar o líder anterior.
**Observar:** quem fala, quem se cala, quem resolve de verdade.
