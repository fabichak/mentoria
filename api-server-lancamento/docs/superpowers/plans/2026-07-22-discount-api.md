# Discount API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single-endpoint Node/Express server, runnable in Docker on a configurable port, that returns a configured word when POSTed the correct password and `403 Forbidden` otherwise.

**Architecture:** `server.js` exports a `createApp({password, word})` factory (pure, testable) and, when run directly, reads config from env, validates it, and listens on `PORT`. Password check uses constant-time compare. Docker layer copies the app and runs it as a non-root user; the port is supplied at runtime via the `PORT` env var.

**Tech Stack:** Node.js 22, Express 5, `node:test` (built-in test runner), `node:crypto` `timingSafeEqual`, Docker (`node:22-alpine`).

## Global Constraints

- Node ESM only: `package.json` has `"type": "module"`; use `import` syntax.
- Express version floor: `express@^5.1.0`.
- Endpoint is exactly `POST /discount`, JSON body `{"password": "<string>"}`.
- Success: HTTP `200`, `Content-Type: text/plain`, body is **exactly** `DISCOUNT_WORD` (no wrapping, no trailing newline added by us).
- Every failure mode — wrong / missing / empty / non-string password, and malformed JSON — returns HTTP `403` with body `Forbidden`. No 400s, no info leaks.
- Password compared with `crypto.timingSafeEqual` over UTF-8 buffers, with a length guard (it throws on unequal lengths).
- Required env vars: `PORT` (optional, default `3000`), `DISCOUNT_PASSWORD` (required), `DISCOUNT_WORD` (required). Missing required var at startup → stderr message + `process.exit(1)`.
- No dependencies beyond `express`. No test framework.

  assert.equal(res.status, 403)

- [ ] **Step 5: Write minimal implementation in `server.js`**

```javascript
import express from 'express'
import { timingSafeEqual } from 'node:crypto'

export function createApp({ password, word }) {
  const app = express()
  app.use(express.json())

  const expected = Buffer.from(password, 'utf8')

  // Constant-time compare. timingSafeEqual throws on unequal-length
  // buffers, so guard length first; a length mismatch is a wrong password.
  function passwordMatches(candidate) {
    if (typeof candidate !== 'string') return false
    const got = Buffer.from(candidate, 'utf8')
    if (got.length !== expected.length) return false
    return timingSafeEqual(got, expected)
  }

  app.post('/discount', (req, res) => {
    if (passwordMatches(req.body?.password)) {
      res.type('text/plain').send(word)
    } else {
      res.status(403).send('Forbidden')
    }
  })

  // Malformed JSON body -> uniform 403; anything else is a real server error.
  app.use((err, req, res, next) => {
    if (err && err.type === 'entity.parse.failed') {
      return res.status(403).send('Forbidden')
    }
    console.error(err)
    res.status(500).send('Internal Server Error')
  })

  return app
}

// Run directly (node server.js): validate env, then listen.
const isMain = import.meta.url === `file://${process.argv[1]}`
if (isMain) {
  const password = process.env.DISCOUNT_PASSWORD
  const word = process.env.DISCOUNT_WORD
  if (!password || !word) {
    console.error('DISCOUNT_PASSWORD and DISCOUNT_WORD must be set')
    process.exit(1)
  }
  const port = Number(process.env.PORT) || 3000
  createApp({ password, word }).listen(port, () => {
    console.log(`discount API listening on ${port}`)
  })
}
```
